# practicas-ml-y-vision

Prácticas de Aprendizaje Automático y de Visión por Computador (Universidad
Politécnica Salesiana, 2026), cada una en su carpeta con su README y sus
dependencias.

| Práctica | |
|---|---|
| [Aprendizaje Automático 1](aprendizaje-automatico/practica-1-consumo-electrico) | Análisis exploratorio del consumo eléctrico de 370 clientes (UCI). |
| [Aprendizaje Automático 2](aprendizaje-automatico/practica-2-demanda-retail) | Predicción de demanda diaria con LSTM frente a Random Forest. |
| [Visión por Computador 0](vision/practica-0-entropia) | Entropía de imágenes por categoría y efecto de modificaciones. |

El repositorio se llamaba `VisionC` y tenía todo bajo una carpeta
`Documents/`. En 2026 se ordenó por materia, se quitaron reportes
autogenerados y las imágenes sin licencia identificable, y se corrigió el
cuaderno de la práctica 2, que no se podía ejecutar completo.
